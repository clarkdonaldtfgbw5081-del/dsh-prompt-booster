# 路线图

当前版本是 MVP，以下方向按优先级排列，不代表承诺时间：

## 近期

0.2.5 已落地具体拦截原因、12 组代表性质量对照，以及独立的浏览器交互验收和 CI 门禁。浏览器使用真实插件组件与编辑器适配夹具，完整 DSH 页面和系统输入法仍在下列待验范围，详见 INTERACTION-ACCEPTANCE.md。

- 完成 DSH Web 与桌面版的完整安装验收：真实输入法、原生快捷键、设置页表单、撤销和卸载。
- 在目标环境继续真实模型评测：0.2.4 已完成 DeepSeek API 76 条 live 与 0.2.0/0.2.1 桌面冒烟；仍需安装版 DSH 宿主触发的同批样例、人工盲评与生产 P90 对照。
- 改进结构化引用（chips）的识别与保留，在引用草稿上安全启用优化。
- 把当前“任务 / 方案 / 偏好”关键词规则替换为更可解释、可测试的本地分类策略。
- 增加英文文档与英文界面文案的覆盖检查。

## 中期

- 更准确的项目摘要与相关片段提取，减少用户手动选择文件。
- 任务展开、模板收藏与可复用的改写配置。
- 真实用户黄金集与人工意图评价，建立下游任务完成率指标。
- 基于实际反馈继续完善已有失败分类与提示，同时保持不泄露提供方异常正文。

## 长期

- 与 DSH 新版本保持兼容的迁移流程和兼容矩阵。
- 在保证“不自动发送 / 不遥测 / 插件不另建独立日志或缓存”前提下的团队级配置与审计视图。

欢迎在 Issue 中讨论优先级，或直接提交聚焦的 PR。
