# 路线图

当前版本是 MVP，以下方向按优先级排列，不代表承诺时间：

## 近期

- 完成 DSH Web 与桌面版的完整安装验收：真实输入法、原生快捷键、设置页表单、撤销和卸载。
- 在目标环境运行真实模型评测，补充自然语言改写质量与延迟数据；现有 5 条桌面样例只用作连通冒烟。
- 改进结构化引用（chips）的识别与保留，在引用草稿上安全启用优化。
- 把当前“任务 / 方案 / 偏好”关键词规则替换为更可解释、可测试的本地分类策略。
- 增加英文文档与英文界面文案的覆盖检查。

## 中期

- 更准确的项目摘要与相关片段提取，减少用户手动选择文件。
- 任务展开、模板收藏与可复用的改写配置。
- 真实用户黄金集与人工意图评价，建立下游任务完成率指标。
- 更细的失败分类与可操作提示，同时保持不泄露提供方异常正文。

## 长期

- 与 DSH 新版本保持兼容的迁移流程和兼容矩阵。
- 在保证“不自动发送 / 不遥测 / 不持久化正文”前提下的团队级配置与审计视图。

欢迎在 Issue 中讨论优先级，或直接提交聚焦的 PR。
